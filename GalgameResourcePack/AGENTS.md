# GalgameResourcePack 工作约定

本文件适用于此技能目录及其子目录。封包前阅读 [SKILL.md](SKILL.md)，归档参数和工具命令以该文件及其引用资料为准。

## 入口与资料

- 资源快照、合并和验证入口是 `scripts/resource_workflow.py`；操作前阅读 [资源交接与重建](guides/resource-workflow.md)。
- 工具位于 `tools/`，相对于本技能根目录解析。按目标格式阅读 `commands/` 中对应的 CLI 文档；引擎经验按引擎名收录到 `engine/`。
- `init/merge` 可管理已确认路径的资源清单；`pack/verify` 的后端仅支持 GARbro。其他 CLI 需单独调用并执行往返提取与比对。
- 成功重建后的方法按 [经验闭环](guides/engine-learning.md) 自动记入用户本地库，核对真实样本与可分发性后收录；运行前先查历史条件与失效记录。

## 封包与验证约束

- 根据原始归档证据确认格式、写入能力及必要创建参数。格式可读不等于可写，默认选项不能证明原始设置；无法表达必需参数时报告限制。
- 完整重建保留全部未修改资源，按完整相对路径合并替换文件。仅在已确认游戏支持时使用补丁归档，不通过扁平化、静默增加或遗漏资源解决匹配问题。
- 保留原始归档及替换输入，默认使用新的输出路径。基线清单、暂存目录、输出归档和验证目录按参考文档分别存放；元数据不得混入归档资源。
- 归档格式与音频编码分别验证；改扩展名不是转码。保留条目身份、顺序及格式要求的关联文件，不混用 CPK 索引、CPK ID 和 AWB wave ID。
- 创建后重新列出并原样提取归档，比对预期路径、数量和哈希。解码长度及引擎边界验证、游戏播放测试分别记录，不能用哈希通过替代。
- 已知解码长度或越界问题未修复时停止安装。安装按用户授权范围执行，封包请求本身不自动包含安装。

## 维护与验证

- 保持随附工具的运行依赖和许可证完整；非工具变更不需要重编译第三方源码。
- 修改资源流程后，在本技能根目录运行下面的集成检查。需要 GalTTS 的运行依赖、FFmpeg 和随附 GARbro；若 FFmpeg 不在 PATH 中，将 `$ffmpeg` 改为其绝对路径。

```powershell
$ffmpeg = (Get-Command ffmpeg -ErrorAction Stop).Source
python scripts/test_resource_workflow.py --ffmpeg $ffmpeg --garbro tools/GARbro-cli/GARbro.Console.exe
```

- 测试使用临时合成资源和模拟后端，不启动真实 TTS 模型。仅改文档时核对链接和命令；缺少依赖时如实记录未运行的检查。
- 交付绝对归档路径、封包模式、关键设置、替换及保留数量，以及资源比对、引擎验证和播放测试各自的结果。
