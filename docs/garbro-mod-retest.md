XP3 与 WARC 的显式选项试验使用本地只读诊断程序和技能随附的 Mod DLL、数据库。该程序只读取指定成员流并计算哈希。XP3 仅在独立检查整个索引符合标准分段、全部成员标志为零且具备 Adler-32 字段后提供无额外归档过滤器的选项。原始包和旧输出留作证据。详情见 [XP3 读取边界](../GalgameResourceExtract/engine/kirikiri.md) 和 [Mod CLI](../GalgameResourceExtract/commands/garbro.md)。

本表所有样本的 **GARbro 封包状态为 Mod CLI 无写入入口**。本轮未创建游戏归档，也未验证其他写入工具的兼容性。需要回封时，按原格式版本、路径、过滤及包装要求选写入器，再对比归档索引与同层级成员字节。样本以外的归档和游戏内加载待单独验证。 [封包工具索引](../GalgameResourcePack/commands/index.md)
