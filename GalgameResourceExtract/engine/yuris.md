# YU-RIS：YPF 与 YBN

## 解包与封包工具

| 工具与来源 | 解包或读取用途 | 封包或回写用途 | 适用版本与限制 |
| --- | --- | --- | --- |
| [GARbro CLI](../commands/garbro.md)，随附，格式标签 `YPF` | 读取 YPF 索引，按标志解压成员；命中已有方案时还可能还原 YSTB 脚本字节 | 创建旧版索引的 YPF，可保存子目录；必须明确 `Key` 与 `Version` | 当前 CLI 创建参数接受 `1` 至 `472`，排除 `222`；不表示此范围内所有商业分支都兼容。不支持新版 64 位偏移索引的写入，也不自动恢复读取时剥除的自定义脚本变换；见[实现][ypf] |
| [YU-RIS 官方 SDK 与手册][official]，外部，未随附 | 核对 YST 语言、命令和 E-ris 宏层 | 对拥有对应工程源码的项目，使用同版本官方编译与资源制作流程 | 不是从任意发行版无损恢复工程的工具；公开 SDK 版本不能直接代表定制商业分支 |
| [yuri][yuri]，外部研究与读取实现参考，未随附 | 核对 YPF 版本差异、YBN 家族与 YSTB 结构 | 本技能没有将其作为随附封包或脚本回写工具 | 所引仓库含公共版本和定制版本讨论；本页只采用有结构依据的公共方法，不携带个别项目参数 |

## 格式特征与编码方式

| 格式或层级 | 通用特征 | 编码方式与判定依据 |
| --- | --- | --- |
| YPF 归档 | `YPF\0` 标识、版本、条目数及索引大小；条目含名称、类型、压缩标志、存储与展开大小、偏移及校验值 | 所引 GARbro 读取和写入器使用 CP932 文件名；名称长度置换与名称 XOR 属于索引变换，不属于字符编码；见[实现][ypf] |
| YPF 成员压缩与版本差异 | 按条目压缩标志决定是否解压；新旧布局的偏移宽度及校验算法不同 | 所引实现对压缩成员使用 zlib；不能因同为 `.ypf` 就沿用某一版的字段宽度、校验算法或密钥。新版 64 位偏移等差异可对照[格式研究][yuri] |
| YBN 家族 | `.ybn` 是一组二进制格式：`YSTB` 为编译脚本，另有命令定义、标签、变量、脚本列表等不同签名 | 不把全部 YBN 当成正文字符串表。先按四字节标识分流，再验证版本、记录长度和表边界；见[格式研究][yuri] |
| YSTB 脚本 | 指令和参数区、表达式及字符串相关区按版本布局；可能另有 XOR 处理 | 正文按同版本读取实现及命令边界确认。所引公共版本研究使用 CP932；这不是所有本地化分支的编码保证。脚本 XOR 与 YPF 名称 XOR 是不同层级、不同参数 |
| YST 源码与 E-ris 宏 | YST 编译为 YBN；E-ris 在引擎命令之上提供 ADV 功能与宏 | 源码编码、编译脚本字符串及导出 JSON/TXT 编码分别确认。文本导出的 UTF-8 不证明原脚本为 UTF-8 |
| 图像、音频、视频等成员 | 提取后按文件头和对应脚本引用识别；归档类型字段仅作为辅助线索 | 媒体容器及编码独立于 YPF 和 YSTB；不根据 `.ypf` 指定统一音频编码 |

## 注意事项

不要仅凭可见版本号选择写入器。公共版本的字段变化可以提供候选路线，定制商业分支仍须用索引完整解析、名称校验、条目边界和代表性成员证明。所有项目密钥及个别布局修正留在本地。

GARbro 解包可能同时完成成员解压；当方案包含非零脚本参数时，还可能改变 YSTB 字节。先记录处理层级，保留原始归档和必要的存储成员。未经确认，不把已经还原的 YBN 直接交给只负责归档的创建器并声称完成原样往返。

对白记录应来自完整的命令与参数解析。需要时检查配套命令定义、标签、变量和脚本列表；E-ris 宏和任务切换可能把文本、显示姓名和语音调用分散到不同代码段。需要对白与语音关联时追踪实际参数与状态，不把连续的字符串、数组索引或文件排序当作最终对应关系。

封包测试须核对原始版本与名称编码，重新提取并比较名称、条目数和成员字节。新版索引或未知 ScriptKey 回写仍是当前随附创建器的缺口；成员一致也不能单独证明引擎会加载或脚本语义正确。

## 来源、版本与验证边界

- [YU-RIS 官方手册][official]用于语言与命令的语义依据，按 2026-10-22 在线版本核对；具体发行版仍以其配套资料为准。
- GARbro 参考固定为 `b09ee4570ccb1daf6ac56710ee8934dc0b8baeb0`（MIT）；`yuri` 研究参考固定为 `183b85ef403d0d5d6bde0af76353e90e2ca970ca`，仅作为外部资料链接，不随附其源码。
- 验证等级为文档与源码核对，未宣称真实游戏、所有 YPF 版本或所有 E-ris 宏的验证。工具支持、格式完整性和对白与语音关联分别验收。
- 失效条件：未知签名、索引或校验算法不匹配、指令版本未知、字符串编码冲突或定制脚本加密无法确认。此类参数不因一款游戏成功而写成引擎默认规则。
