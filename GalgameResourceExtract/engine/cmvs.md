# CMVS / Purple Software：CPZ

从归档头区分 CPZ 版本，再核对逻辑成员。旧作、补丁和发行版可在同一安装目录中使用不同容器。

## 解包与封包工具

| 工具与来源 | 解包用途 | 封包用途 | 适用范围与限制 |
| --- | --- | --- | --- |
| 随附 [GARbro Mod](../commands/garbro.md) 与 [序号解包 CLI](../commands/garbro-archive.md)，[CPZ3 源码][cpz3]与 [CPZ5–7 源码][cmvs] | 列出 CPZ 索引并导出解密、解压后的逻辑成员；按索引序号保留同名条目 | 当前路线无经过验证的写入器 | Mod 1.0.2.2 的 CPZ3、CPZ5、CPZ6、CPZ7 已通过真实样本验证；所选读取器与方案依版本和样本而定 |
| 外部 [Akaibu CLI 0.1.17][akaibu]，Unlicense | 对匹配方案的 CPZ7 解包，可作为另一读取实现复核 | 当前路线只读 | 需手动选择当前发行版的方案，保留源归档名。Windows 真实样本已验证；日志可能含样本专用参数，留在本地 |
| 随附 [PKP v0 CLI](../commands/pkp.md) | 导出符合指定布局的补丁归档成员和存储字节 | 只读 | 以 `PKP\0`、版本、索引和全部长度为条件；与 CPZ 分开验收 |
| 随附 [GARbro 图像批处理](../commands/garbro-images.md) | PB3 等原生图像的后续解码候选 | 无经过验证的写入器 | 应另测当前 PB3 变体、差分引用与父图合成 |

## 格式特征与编码方式

| 层级 | 识别线索 | 验证方式 |
| --- | --- | --- |
| CPZ 容器 | 文件首四字节为 `CPZ3`、`CPZ5`、`CPZ6` 或 `CPZ7` | 读取版本由原始文件头确定，CLI 的读取标签可能合并多个版本。按对应版本的实现核对名称解码、索引和成员变换。 |
| 脚本与配置 | 常见 `script.cpz` 中的 `.ps2`、`.ps3`；可见以 `PS2` 开头的二进制成员 | 保存原始成员和路径。文字编码、消息消费者和存档坐标需要另取脚本证据。 |
| 图像、音频及视频 | 可见 PB3、PNG、Ogg 等原生文件头 | 分别检查媒体签名和解码。图像归档与其差分、蒙版及画布组合须独立验证。 |
| 补丁归档 | 同时检查归档头、版本和目录结构 | 对 `PKP\0` 匹配项转至 [PKP 命令](../commands/pkp.md)。其他补丁按自身结构识别，保留独立来源与同名项。 |

## 验证要点

- 比较列表与导出清单的成员名、偏移、存储长度和重复次数。检查全部输出大小，并按资源类型抽检文件头和哈希。列表成功、逻辑流成功和媒体语义各自验收。
- 索引或成员输出与同版本工具的预期不符时，保留原包，记录读取器与方案并暂停该候选。只在新工作目录重试。
- 试用 Akaibu 时，在新的目录运行 `akaibu_cli.exe -o NEW_OUTPUT_DIRECTORY INPUT.cpz` 并选定匹配方案。抽检媒体签名，逐项核对清单、存储范围和输出长度。仅有退出码不足以确认成功。
- 补丁加载顺序、脚本语义、CG 差分组合、封包和游戏内运行均须按当前样本另验。

- 阶段：extract

- 识别 CPZ3、CPZ5、CPZ6 或 CPZ7 文件头，并确认固定版读取器选中的格式。
