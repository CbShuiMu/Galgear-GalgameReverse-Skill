# Yuka：YKC 与 YKS

## 解包与封包工具

| 工具与来源 | 解包用途 | 封包用途 | 适用范围与限制 |
| --- | --- | --- | --- |
| [GARbro Mod CLI](../commands/garbro.md)，随附 | 读取 YKC 索引、解包逻辑成员 | Mod CLI 不提供封包；需另选匹配的引擎工具 | 真实 YKC001 样本的索引与成员已核验。脚本消费者与封包未验证。 |

## 格式特征与编码方式

| 层级 | 识别与验证 |
| --- | --- |
| YKC001 / YKC002 | 归档头记录索引偏移与长度，每个条目记录名称和载荷各自的偏移及大小。所引实现对 YKC001 使用 CP932，对 YKC002 使用 UTF-8。 |
| YKS001 | 命中已标记的 YKS001 版本时，读取器会还原文本区并清除相应标志。归档存储字节与解包脚本可能大小相同但内容不同。 |
| 媒体 | 图像、音频与补丁成员按自己的签名识别。文件名编码不能推出脚本文字或媒体编码。 |

## 注意事项

保留原始归档。校验解包脚本时按 YKS 头的文本起点、范围和处理标志比较，不能仅用成员长度判断是否原样。
