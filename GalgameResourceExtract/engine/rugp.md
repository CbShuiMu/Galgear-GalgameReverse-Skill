# rUGP / RIO

## 解包与封包工具

| 工具 | 方向 | 适用范围、来源与限制 |
| --- | --- | --- |
| 随附 AgeReVerse RIO 目录 CLI | 只读目录 | 固定提交的 ICI／RIO 对象目录读取，支持额外卷与范围检查；[命令](../commands/age-rio.md)。不提取图像载荷，不封包 |
| 随附 GARbro / GameRes | 解包／图像读取候选 | 取决于匹配的 RIO 版本与对象类；当前样本未取得可验证图像，不作为成功适配 |
| 封包 | 未验证 | 没有本轮可交付的 RIO 写入或完整重建能力 |

## 格式与编码

ICI 是对象目录线索，RIO 可包含多个卷。先区分逻辑对象、全局偏移、卷内偏移与声明范围；按当前读取实现核验目录头、边界、缺卷和对象类。目录元数据还原与资源载荷处理是不同阶段，文件扩展名或类名不能确定图像压缩方式。

随附目录 CLI 的通用实现与上游读取器保留在工具源码中。单款游戏的特殊布局、未还原名称、对象参数与原始数据只保存在用户本地。

## CG 提取状态与限制

当前真实样本仅取得原版及补丁中的图像对象目录，尚未成功解码为可验证图像。`Cr6Ti` 等标签是目录分类，`extent` 不是完整差分语义证据。不要将这些目录行计入成功 CG 文件数，也不要根据重复或占位名称去重。

后续需要匹配载荷解码、子图／透明度及引用关系；长时间受阻时保存诊断后跳过。逐款结果见 [CG 状态表](../catalog/cg-status.md)。
