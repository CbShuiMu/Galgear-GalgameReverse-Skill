siglus-ssu.exe is a self-contained Windows x64 console application built with
official CPython 3.12.10, PyInstaller 6.21.0 and hooks-contrib 2026.9.
Runtime licenses are in PYTHON-LICENSE.txt and licenses/.
Optional Pillow, psutil and Rust native acceleration are not included.

Usage, limitations, verification and build instructions are maintained in
the skill's commands/siglus-ssu.md. The adapter only replaces existing scene
DAT files and preserves metadata from the original PCK. Modified DAT files
with embedded original source, unknown layouts, links and existing outputs
are refused. Only synthetic archive verification has been performed.

Build with a clean official Windows Python 3.12 installation:
python -m pip install PyInstaller==6.21.0 pyinstaller-hooks-contrib==2026.9
python build.py --output C:\Temp\siglus-cli-build
