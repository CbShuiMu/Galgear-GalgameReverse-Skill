Majiro CLI 1.0 - ARC V3 lowercase CP932 flat-name subset

This package contains no original game content, fonts, game patch logic,
hardcoded project paths, GUI, downloaded executable, or native dependency.
Python 3.9 or later is required. The runtime uses the standard library.

majiro_cli.py is a GalSkill adaptation dated 2026-10-22, distributed under
the MIT terms of LICENSE.txt. It adds bounded structural/name/hash checks,
path and reparse checks, explicit CLI commands and non-overwriting output.
Source pins, file hashes and synthetic validation limits are in SOURCE.json.

The original helper applies lower() for hashing. The CLI requires names
already equal to lower(), and never silently renames input resources.
Only canonical CP932 names are supported. ARC V1/V2 and MJO compilation,
encryption, image or audio transformations are not supported by this CLI.
